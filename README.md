# 🇮🇳 NIDHINETRA

### See the Risk. Track the Progress. Strengthen Accountability.

**An AI-powered public fund intelligence platform for smarter MPLADS monitoring across India.**

NIDHINETRA aims to transform public fund and development project data into actionable insights through role-based dashboards, project monitoring, fund utilization analysis, and AI-assisted risk identification.

> **Our vision:** Move from static reporting to proactive, transparent, and data-driven public fund monitoring.

## 🏛️ Four-Level Monitoring Architecture

NIDHINETRA is designed around four stakeholder roles:

* **Ministry Admin** — National-level monitoring and oversight.
* **State Nodal Authority** — State-level fund and project monitoring.
* **District Authority** — District-level implementation monitoring.
* **Member of Parliament (MP)** — Constituency-level development monitoring.

The objective is to provide each role with relevant information while maintaining appropriate access restrictions.

## 🧠 AI-Powered Risk Intelligence

The platform aims to surface patterns that may deserve closer review, including:

* Unusual project expenditure patterns.
* Potential duplicate project records.
* Unexpected project implementation delays.
* Inconsistencies in financial and project data.
* Potential inefficiencies in fund utilization.

**Important:** An anomaly is a signal for investigation, not proof of fraud. Analytical results require validation and human review before any decision is made.
